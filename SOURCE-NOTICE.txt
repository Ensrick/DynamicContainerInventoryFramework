This binary is modified from upstream. In addition to the fork's Skyrim
1.7.104 / SKSE 2.3.1 / Address Library format 5 support and vendor-only rule
fix, this revision rejects nonpositive signed inventory deltas before any
removal, replacement, leveled-list resolution, or random-add iteration.
Keyword rules retain signed per-entry counts and saturate their positive total
instead of wrapping. Positive leveled-list counts remain exact through 32,767
and clamp above the engine's signed 16-bit limit.

Count diagnostics now identify the JSON path, friendly rule name, container
and base FormIDs, plus source and target FormIDs where available. Focused tests
cover -16, -15, 0, 1, 32767, 32768, aggregate overflow, and the owned C.O.I.N.
DE5012 -> DE5016 regression seam.

The distribution contains the rebuilt DLL, debugging symbols, build manifest,
this source notice, and the Apache-2.0 license. It intentionally contains no
INI or JSON runtime configuration; the official CDF package remains
authoritative for those files.
